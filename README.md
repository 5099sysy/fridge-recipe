# fridge-recipe

1. CSV 데이터 불러오기
 - name, ingredients, difficulty, time 형태의 csv 파일
 - 리스트 생성
2. 냉장고 재료 저장
 - session_state 이용하여 추가, 삭제, 유지
3. 유통기한 관리
 - 날짜와 유통기한 차이 계산
 - 3일 이하 재료 우선 소비 대상(빨간색, 경고, 우선순위 증가)
 - 유통기한 순 정렬
4. 추천 점수 계산
 - 추천 이유 생성
 - 추천 정도 분류
 - 필터 기능
5. 결과 출력

[점수 계산 방법]
일치 재료 수
레시피 전체 재료 개수
(일치 재료 수/ 전체 재료 수)
70점 비율 반영
+
유통기한 임박 재료 1 개당 15점 추가
